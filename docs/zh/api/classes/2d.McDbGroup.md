# Class: McDbGroup

[2d](../modules/2d.md).McDbGroup

组对象

**`Example`**

```ts
  选择一堆对象，把他们创建到一个组中 。
  let ss = new MxCADSelectionSet();
  if (!await ss.userSelect("选择要做成组的对象:")) return;
  if (ss.count() == 0) return;
  let mxcad = MxCpp.getCurrentMxCAD();
  mxcad.getDatabase().CreateGroup(ss.getIds());
```
